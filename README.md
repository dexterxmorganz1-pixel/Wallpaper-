# Aura Wallpapers — Android project

This is an Android Studio project for the Aura Wallpapers app.

## Features
- Wallpaper gallery with categories and search
- Favorites saved locally on the device
- Full-screen wallpaper preview
- Android `WallpaperManager` integration to set the selected image as the device wallpaper
- Dark UI designed for phone screens

## Build an APK
1. Install Android Studio and the Android SDK (API 35).
2. Open this folder (`AuraWallpapersAndroid`) in Android Studio.
3. Allow Gradle sync to complete.
4. Choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**, or use the terminal:
   `./gradlew assembleDebug` (after a Gradle wrapper has been generated by Android Studio).
5. The APK will be under `app/build/outputs/apk/debug/`.

The APK is not included in this ZIP because this environment does not have the Android SDK/Gradle build toolchain installed. This is the source project to build it.

## Notes
- Wallpaper images load from Unsplash, so internet access is needed.
- Favorites are stored locally in WebView local storage.
- This is a debug-build project template; configure a private signing key for a release build.


## Build an APK using only your phone

This project includes a GitHub Actions workflow at `.github/workflows/android-apk.yml`.
1. Create a GitHub repository and upload the *contents* of this project folder (not the ZIP file itself).
2. Make sure the default branch is named `main`.
3. Open the repository on GitHub in your phone browser and tap **Actions**.
4. Open **Build Android APK**. If it has not started automatically, choose **Run workflow**.
5. Wait for the run to finish successfully, open the completed run, and download the `AuraWallpapers-debug-apk` artifact.
6. Extract the downloaded artifact ZIP on your phone; the `.apk` inside is the app installer.

The APK is a debug build for personal testing, not a Play Store release.
